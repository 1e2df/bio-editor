Como criar o token

Jeito mais fácil (token clássico, já vem com a permissão marcada):

  1. Abra este link (já vem com public_repo marcado).
  2. Em Expiration, escolha por quanto tempo o token vale.
  3. Desça até o fim e clique em Generate token.
  4. Copie o código que começa com ghp_ e cole aqui.

Jeito mais restrito (token fine-grained, acessa só este repositório):

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e selecione este repositório na lista.
  3. Só depois disso aparece Permissions: abra Repository permissions (ou clique em Add permissions), encontre Contents e mude de No access para Read and write.
  4. Clique em Generate token, copie o código que começa com github_pat_ e cole aqui.

Não compartilhe o token com ninguém.
