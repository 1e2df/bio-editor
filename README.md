# Bio com editor

Página de bio pessoal com um editor visual, baseada em [Cybercodedude/Mycoolbio](https://github.com/Cybercodedude/Mycoolbio) (licença MIT).

## Como editar

1. Abra `editor.html` no site publicado (ex.: `https://SEU-USUARIO.github.io/bio-editor/editor.html`).
2. Altere nome, biografia, foto, plano de fundo, música e links. A prévia atualiza na hora.
3. Em **Publicar**, informe `usuário/repositório` e um token do GitHub com permissão **Contents: Read and write** neste repositório.
4. Clique em **Publicar no GitHub**. O site atualiza em 1 a 2 minutos.

Todo o conteúdo fica em `config.js`; também dá para editar esse arquivo à mão.
